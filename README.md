# To-Do List App

This is my first To-Do List application. I built it to practice DOM manipulation and working with localStorage.

## What it does
- You can add new tasks.
- You can delete tasks by clicking the X button.
- The tasks are saved in the browser, so if you reload the page, they are still there.

## Built with
- HTML
- CSS
- JavaScript (Vanilla)

## Note
The app interface is in Spanish because I wanted to practice with my own language, but all the code and variables are in English.
